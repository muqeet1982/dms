{% comment %} The house style for a printed document: invoice, order, and anything added later. Written for A4 and for a laser printer in an office, which decides most of it — hairline rules instead of filled blocks so a draft does not drink toner, 10.5px text that survives a photocopy, a table header that repeats when the lines run over a page, rows that never split across one, and a page number in the margin so a customer can tell when a sheet is missing. The totals never break away from the lines they belong to. Blocks a document fills in: `doc_title`, `doc_ref` (the number), `status`, `meta` (the key/value strip), `parties`, `lines`, `totals`, `words`, `notes`, `signatures`.
