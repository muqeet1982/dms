{% comment %} The sheet the driver carries out of the warehouse: the stops in sequence, what to drop at each one, what to collect, and somewhere to sign. It deliberately does not extend purchasing/_doc_base.html. That base is built for a one-table document and cannot express what a driver's sheet needs: per-stop blocks that never split across a page, a table header that repeats when a stop runs over, and signature boxes. The page, colours, fonts, table and badge styling below are taken from that base unchanged, so a dispatch sheet still reads as the same company's paperwork as a purchase order or an invoice. {% endcomment %} Dispatch Sheet {{ trip.number }}
